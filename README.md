# Mini CRM Web App with AI Assist

A full-stack CRM web application built with Django that helps users manage contacts, deals, and follow-up emails.

## Features

- User Sign Up and Login
- User-specific contact management
- Add, Edit, Delete and Search Contacts
- Deal Pipeline Management
- Drag and Drop Deal Stages
- New
- Contacted
- Qualified
- Won
- Lost
- AI-assisted follow-up email generation
- User-specific deals and contacts
- Secure authentication
- SQLite database
- Responsive and professional CRM interface

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Git
- GitHub
